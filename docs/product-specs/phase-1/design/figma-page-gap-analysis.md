## 需在 Figma 中补充的 Frame（Figma AI Prompt）

### 运营端（若缺失）

```
为「职优越导师平台-运营端」生成 B 端后台，角色=运营（派单定价，不能审核专家）：
工作台、学员列表、学员档案、项目列表、创建项目（含定价+指定专家）、项目详情（含完成确认按钮）、专家池、专家档期、交付空间
风格：与专家端统一，侧边栏导航，主色 #2563eb
```

### 管理员端（若缺失）

```
为「职优越导师平台-管理员端」生成后台，角色=管理员（仅专家认证审核，不能派单）：
登录、首页、认证审核队列、专家详情（通过/拒绝）、专家列表
```

### 学员轻量端（若缺失）

```
学员端 H5/轻量 Web：短信登录、交付空间（与专家消息、文件列表、加入视频按钮）
```
