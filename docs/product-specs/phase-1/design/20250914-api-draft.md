# Phase 1 API 草案（Catalog）

- **日期**: 2025-09-14
- **版本**: v0.3 — Blocking Q&A 全部完成
- **约定**: 前缀 `/api/v1`；JSON；`{ code, message, details? }`
- **鉴权**: Bearer JWT + RBAC

### 角色与 API 前缀

| 角色 | 角色码 | API 前缀 |
|------|--------|----------|
| 专家 | `expert` | `/experts/me`, `/projects`, `/dashboard`, `/income` |
| 运营 | `ops` | `/ops/*` |
| 管理员 | `admin` | `/admin/*` |
| 学员 | `student` | `/student/*` |
| 公共 | — | `/auth/*`, `/dictionaries/*` |

## 1. 认证 `FEAT-P1-001`

| Method | Path | 说明 | 角色 |
|--------|------|------|------|
| POST | `/auth/register` | 专家开放注册 | public |
| POST | `/auth/login` | 登录（多角色，返回 role） | public |
| POST | `/auth/logout` | 登出 | authed |
| POST | `/auth/refresh` | 刷新 token | authed |
| GET | `/auth/me` | 当前用户 + 角色 + 状态摘要 | authed |

### 学员登录 `FEAT-P1-STU`

| Method | Path | 说明 |
|--------|------|------|
| POST | `/auth/student/otp/send` | 向手机号发送 OTP `{ phone }` |
| POST | `/auth/student/otp/verify` | 验证 OTP，返回 JWT |
| GET | `/auth/student/magic` | magic link token 验证登录 `?token=` |
| POST | `/ops/students/:id/send-login-link` | 运营触发短信登录链接 |

> 学员 JWT  scope 受限：仅可访问已关联项目的交付空间。

### 阿里云 RTC 集成（Q-005-FU）

- 产品：**阿里云实时音视频 RTC**
- 现状：已支持 **1v1 视频**；**暂无 API 文档**
- 适配器：`AliyunRtcMeetingProvider implements MeetingProvider`
- 方法：`createChannel(projectId, appointmentId)` / `getJoinToken(userId, role)`

```json
{
  "startAt": "2025-09-25T20:00:00+08:00",
  "endAt": "2025-09-25T21:00:00+08:00",
  "topic": "模拟面试",
  "nodeId": "uuid",
  "rtcChannelId": "aliyun-channel-id"
}
```

### 入账触发（Q-006-FU）

```
POST /projects/:id/completion/submit     (expert)
  → status: pending_ops_review

POST /ops/projects/:id/completion/confirm (ops)
  → project.status = completed
  → INSERT income_lines (amount = project.pricing.totalAmount)
  → expert 账本可见
```

> V1 **无** `/income/withdrawals`（仅账本展示）。

## 11. 核心枚举

`incomplete` | `pending_review` | `certified` | `accepting` | `paused` | `disabled`

### ProjectStatus
`draft` | `pending_confirm` | `in_progress` | `pending_completion_review` | `completed` | `rejected` | `cancelled`

### ProjectCompletionStatus
`not_submitted` | `pending_ops_review` | `confirmed` | `rejected`

### IncomeStatus
