### 术语与角色

| 业务用语 | 系统角色码 | Phase 1 职责 |
|----------|-----------|--------------|
| 专家 / 导师 | `expert` | 入驻、能力档案、接项目、交付、记录、看收入 |
| 运营 | `ops` | 学员/项目 CRUD、派单、定价、协调预约、查看专家档期 |
| 管理员 | `admin` | 专家认证审核（通过/拒绝）、禁用专家、平台配置 |
| 学员 | `student` | 运营创建账号；短信/链接登录；**仅交付空间**（轻量学员端） |

## 已答复问题（跟进）

### Q-004-FU · 学员如何参与沟通？ ✅

| 字段 | 值 |
|------|-----|
| 答复日期 | 2025-09-14 |
| 结论 | **B) 运营创建学员账号；学员通过短信/链接登录交付空间** |
| V1 范围 | 轻量学员端：登录 + 项目交付空间（消息/文件/入会）；非完整学员 App |

**流程**：
1. 运营创建学员（含手机号）
2. 系统发送短信 magic link 或 OTP
3. 学员登录后仅可访问已关联项目的交付空间
4. 可与专家在 `expert_student` 通道沟通

### Q-006-FU · 收入入账触发规则 ✅

| 字段 | 值 |
|------|-----|
| 答复日期 | 2025-09-14 |
| 结论 | **项目完成时一次性入账**（非单节点入账） |

**项目完成条件（须全部满足）**：
1. 专家侧：上传并提交全部要求的**课件 / 交付内容**（deliverables）
2. 运营侧：**确认完成**（review & approve completion）
3. 系统：项目状态 → `completed`，生成 `IncomeLine`（金额 = 运营项目定价）

```
专家提交完成申请 → 运营审核确认 → 项目 completed → 专家账本 +¥
```
