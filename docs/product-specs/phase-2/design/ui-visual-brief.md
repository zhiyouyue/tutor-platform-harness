# Phase 2 UI 视觉 brief（Figma 对齐用）

- **原则**：大标题 + 一句说明 + 白卡片；避免 API/JSON/技术词
- **色（2026-10 统一）**：深蓝 `#0A2540`、主蓝 `#1565D8`、浅蓝 `#F4F9FF`；见 `frontend/src/index.css` 与 [UI-ACCEPTANCE-FIGMA.md](../../UI-ACCEPTANCE-FIGMA.md)
- **字体**：系统 sans，标题 22/600，正文 14/400
- **页面**：运营（首页/学生/项目/课程/收入）、学员（首页/我的课程/在线课堂）

**Figma 参考稿**：[职优越导师 Phase2 UI](https://www.figma.com/design/6ioRMwGOMxkRXBbR14aOUR)（MCP 自 localhost 捕获登录页；运营/学员页以 `SimpleScreen` 为落地标准。）
