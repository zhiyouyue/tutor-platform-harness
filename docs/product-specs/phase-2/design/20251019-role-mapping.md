# Phase 2 角色映射

| 产品板块 | 系统实现（Phase 1/2） | 说明 |
|----------|----------------------|------|
| 公司后台 · 专家管理 | `admin` + 部分只读 `ops` | 认证审核仅 `admin`；专家列表运营可见 |
| 公司后台 · 学生/项目/财务 | **拆分** | Phase 2 仍用 `ops` 承载班主任能力；独立「公司员工后台」登录留 Phase 3 |
| 班主任侧 | `ops`（UI 文案：运营·班主任） | 学员、课程安排、确认完成 |
| 专家侧 | `expert` | 不变 |
| 学生侧 | `student` | 不变 |
