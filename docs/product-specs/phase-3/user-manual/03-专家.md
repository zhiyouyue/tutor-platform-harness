# 专家使用手册

## 首次使用

1. **注册**并登录  
2. 完善**个人资料**与**能力**  
3. 提交**认证**，等待管理员通过  

## 我的项目

- 待确认 → 点「接受」  
- 进行中 → 点「详情」填写辅导记录、交付物  
- 全部完成后 →「提交项目完成」  

## 我的时间

- 设置每周可辅导时段  
- 可添加「临时不可用」  

## 近期辅导安排（课次）

- 查看学员、时间、主题  
- **进入课堂**：平台内音视频（需浏览器允许摄像头/麦克风）  
- **备用链接**：若班主任填写了外部会议链接  
- **标记课次完成**：上完课后点击，等待班主任确认  

## 收入

- **收入**页查看已入账与待结算汇总
