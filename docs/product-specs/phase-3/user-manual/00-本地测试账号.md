## 这四个账号的状态

| 账号 | 显示名 | 手机号 | 状态 |
|------|--------|--------|------|
| admin | — | 13800000001 | 启用 |
| ops1 | 运营一号 | 13800000002 | 启用 |
| expert1 | 测试专家 | 13800000003 | 启用，认证已通过，可接项目 |
| student1 | 测试学员 | 13800000004 | 启用 |

`expert1` 已审核通过，用来点专家工作台。若要测「提交认证 → 管理员通过」，请在专家入口点「注册」另建一个新账号，再用 `admin` 去审核。

班主任的「学生」列表只显示自己负责过项目的学员，所以 `student1` 可能暂时不在 `ops1` 的列表里。学员端仍可用 `student1` 登录。要在班主任端看到学员，用 `ops1` 进入「学生 → 添加」新建，或给 `student1` 创建项目。

## 建议点击顺序

1. `admin`：打开待审核列表，确认能看到专家认证入口。
2. `ops1`：打开首页、学生、项目、课程、收入五个菜单。
3. `expert1`：打开我的项目、我的时间、近期辅导、收入。
4. `student1`：打开我的课程。课表为空是正常的，还没有排课。
