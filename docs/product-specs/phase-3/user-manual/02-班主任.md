# 班主任使用手册

## 您能看到什么

登录后左侧：**首页 · 学生 · 项目 · 课程 · 收入**。仅显示**您负责的项目**及相关学生、课次（Phase 3）。

## 首页

- 查看负责学生数、进行中项目、待确认完成、本周课次  

## 学生

1. **添加**：点「添加」，填姓名与手机号，保存  
2. **批量添加**：点「批量添加」，每行「姓名,手机号」  
3. **发登录链接**：列表中点「发登录链接」，将链接发给学员  

## 项目

1. **创建项目**：选学生、专家、填写标题与金额、辅导类型  
2. **发布给专家**：专家端「待确认」中接受  
3. **查看详情**：API 已支持 `GET /ops/projects/:id`（前端详情页 Phase 3 增强中）  

## 课程（课次）

1. **新建课次**：选项目 → 选日期 → 选专家开放时段 → 创建  
2. 系统会自动准备在线课堂（需环境配置 RTC）  
3. **确认课次完成**：专家标记完成后，在课程列表点「确认完成」→ 触发课次入账  

## 收入

- **收入**页查看所负责项目的签约总额汇总  

## 常见问题

| 情况 | 处理 |
|------|------|
| 学员进不了课堂 | 检查是否已排课；联系技术确认 RTC 配置 |
| 专家时段排不上 | 请专家在「我的时间」中设置每周可辅导时段 |
