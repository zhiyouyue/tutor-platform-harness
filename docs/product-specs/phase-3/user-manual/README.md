面向**非技术用户**。按角色阅读对应章节。

本地点击测试的账号密码见 [00-本地测试账号.md](./00-本地测试账号.md)。

| 手册 | 角色 | 文件 |

| 公司后台（管理员） | 审核专家、全平台运维 | [01-管理员.md](./01-管理员.md) |

## 通用步骤：登录

1. 打开平台首页  
2. 点选您的身份按钮（专家 / 运营 / 管理员 / 学员）  
3. 输入账号与密码（学员也可通过班主任发送的链接登录）  

## 名词

| 词 | 含义 |
|----|------|
| 项目 | 一名学生与一名专家的一段辅导合同 |
| 课次 | 项目下的一次 scheduled 上课 |
| 班主任 | 负责排课与确认完课的运营人员 |
